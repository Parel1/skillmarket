# SkillMarket — Frontend Prototype

Project utama untuk pembelajaran Web Development pertemuan 1–4.

## Struktur

```text
skillmarket/
├── index.html
├── jasa.html
├── detail.html
├── login.html
├── register.html
├── css/
│   └── style.css
└── js/
    ├── data.js
    └── main.js
```

## Cara menjalankan

1. Download/unzip folder.
2. Buka `index.html` di browser, atau gunakan Live Server di VS Code.
3. Belum ada backend/database. Semua data masih dummy di `js/data.js`.
4. Form login/register dan order masih simulasi frontend.

## Roadmap

- Pertemuan 5: Git + GitHub
- Pertemuan 6–7: Node.js + Express + PostgreSQL
- Pertemuan 8: JWT + bcrypt
- Pertemuan 9–10: React
- Pertemuan 11–12: TypeScript + Prisma
- Pertemuan 13: Next.js
- Pertemuan 14: Docker
- Pertemuan 15: Redis
- Pertemuan 16: Deployment

Desain sengaja dibuat modular supaya frontend awal ini bisa dikembangkan menjadi aplikasi full-stack tanpa membuang tampilan dari nol.
